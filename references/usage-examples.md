## Recommended Best Practice Flow

1. User asks for sentiment / pulse on a token
2. TTTpulse fetches Bankr fees + market data
3. Calculates Sentiment Score + Narrative Strength
4. Outputs full Pulse Report with clear drivers
5. User can refine (“deeper analysis”, “compare with X”, “combine with TTTstrat”)
